# print-version-demo

Demo fixture. This action prints its version and does nothing else. It exists to test how Dependabot
updates a GitHub Action, so do not use it in a real workflow.

The test is written up in
[github-actions-miscellaneous-knowledge](https://github.com/getplumber-examples/github-actions-miscellaneous-knowledge).

## Usage

```yaml
- uses: getplumber-examples/print-version-demo@v0.1.0
```
